# ExternalVisuals Music

The Music module supports a local/resource-pack OGG slot named `VORUEM_ALCOHOL_SLOWED`.

Because the requested track is copyrighted audio and no licensed audio file was supplied with the project, the source tree does **not** contain the song itself. To use your own licensed copy, add:

`src/main/resources/assets/externalvisuals/sounds/music/voruem_alcohol_slowed.ogg`

Then enable **Music** in the Audio category. The player is stream-based and fail-safe.
