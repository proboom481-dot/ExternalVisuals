# ExternalVisuals 1.0.0 — Pulse-style visual client

Clean Minecraft 1.16.5 Fabric client focused on PvP visuals. This project is a fresh implementation based on publicly documented feature ideas; it is not a repackaged copy of the All Rights Reserved Pulse Visuals 1.16.5 repository.

## Visual modules
- Hit Particles
- Damage Numbers
- Target HUD
- Critical Effects settings
- Trajectory
- Hitmarker
- Low HP Warning
- Custom Crosshair
- Kill Effects
- Armor & Potion HUD

## Controls
- `Right Shift` — ExternalVisuals menu
- Left-click a module — enable/disable
- Select a module, then click a boolean/mode/slider setting to change it

## Build
Minecraft 1.16.5 / Fabric Loader 0.12.12 / Fabric API 0.42.0+1.16 / Yarn 1.16.5+build.10.
